# 🎬 나만의 영화 퀴즈 게임 (Movie Quiz Game)

Python 기본 문법과 객체 지향 프로그래밍(`Quiz`, `QuizGame` 클래스), JSON 기반 데이터 영속성(`state.json`), 그리고 Git 브랜치 워크플로우를 활용하여 구현한 콘솔 기반 영화 퀴즈 게임입니다. 필수 요구사항뿐만 아니라 보너스 과제 5종(랜덤 출제, 문제 수 선택, 힌트 및 점수 차감, 퀴즈 삭제, 점수 히스토리)까지 모두 구현되어 있습니다.

---

## 1. 프로젝트 개요
- **개발 언어 및 환경**: Python 3.10 이상 (표준 라이브러리 `json`, `random`, `pathlib`, `datetime`만 사용)
- **핵심 설계**:
  - `Quiz` 클래스와 `QuizGame` 클래스로 역할과 책임을 분리한 객체 지향 구조
  - 사용자 입력 예외 처리(앞뒤 공백 제거, 빈 입력, 문자 입력, 허용 범위 초과, `Ctrl+C` / `EOFError` 안전 종료 및 자동 저장)
  - `state.json`(UTF-8) 파일을 통한 퀴즈 목록, 최고 점수, 플레이 히스토리 영구 저장 및 파일 손상 시 자동 복구

---

## 2. 퀴즈 주제와 선정 이유
- **선정 주제**: 세계 명작 및 흥행 영화 (마블 시네마틱 유니버스, 기생충, 인터스텔라, 매트릭스, 타이타닉/아바타 등)
- **선정 이유**:
  - 영화는 누구나 흥미롭게 참여할 수 있는 대중적인 주제이면서도 감독, 명장면, 주요 소재 등 4지선다형 퀴즈와 힌트를 구성하기에 매우 적합합니다.
  - 문제를 풀고 직접 자신이 좋아하는 영화 문제를 추가·삭제하며 게임의 재미와 데이터 영속성을 직관적으로 확인할 수 있어 선정했습니다.

---

## 3. 실행 방법

터미널(또는 명령 프롬프트/PowerShell)에서 프로젝트 루트 폴더로 이동한 뒤 아래 명령어를 실행합니다.

```bash
python main.py
```

## 4. 기능 목록

### 필수 기능
1. **메뉴 표시 및 입력 검증**: 1~6번 메뉴 선택, 공백 제거, 비정상 입력(`abc`, 범위 밖 숫자, 빈 엔터) 안내 후 재입력, `Ctrl+C`/`EOF` 발생 시 안전 저장 후 종료
2. **퀴즈 풀기 (`1번`)**: 등록된 퀴즈를 출제하고 사용자 정답(1~4)을 입력받아 즉시 정답/오답 여부와 해설 출력, 종료 후 100점 만점 기준 점수 계산 및 최고 점수 갱신
3. **퀴즈 추가 (`2번`)**: 새로운 문제, 선택지 4개, 정답 번호(1~4), 힌트를 입력받아 등록 및 `state.json`에 즉시 저장
4. **퀴즈 목록 (`3번`)**: 현재 저장된 모든 퀴즈의 번호와 문제 목록 출력
5. **점수 확인 (`4번`)**: 최고 점수와 최고 기록 달성 시 맞힌 문제 수 확인 (미플레이 시 안내 메시지 출력)
6. **파일 저장 및 복구**: 프로그램 시작 시 `state.json` 자동 로드, 파일이 없거나 손상된 경우 안내 메시지 출력 후 기본 영화 퀴즈 5문제로 자동 복구

### 보너스 기능 (전체 구현 완료)
1. **랜덤 출제**: `random.sample()`을 사용하여 매 게임마다 문제 출제 순서를 무작위로 섞음
2. **문제 수 선택**: 퀴즈 시작 전 풀고 싶은 문제 수를 직접 지정 가능 (그냥 Enter 입력 시 전체 문제 출제)
3. **힌트 기능 및 점수 차감**: 각 `Quiz`에 `hint` 속성 포함, 풀이 중 `0` 입력 시 힌트 출력 및 힌트 1회당 `5점` 차감(중복 열람 시 추가 차감 없음)
4. **퀴즈 삭제 기능 (`6번`)**: 등록된 퀴즈 목록을 보고 원하는 번호의 퀴즈를 삭제한 뒤 `state.json`에 즉시 반영
5. **점수 기록 히스토리**: 최고 점수뿐만 아니라 모든 플레이의 날짜/시간(`YYYY-MM-DD HH:MM:SS`), 푼 문제 수, 맞힌 개수, 힌트 사용 횟수, 최종 점수를 기록하고 `4번` 메뉴에서 전체 내역 출력

## 5. 파일 구조

```text
movie-quiz-game/
├── main.py          # 프로그램 진입점 (QuizGame 인스턴스 생성 및 실행)
├── quiz.py          # 개별 퀴즈 데이터와 동작을 정의하는 Quiz 클래스 및 기본 퀴즈 5문항
├── quiz_game.py     # 게임 진행, 입출력 검증, 파일 저장/복구를 담당하는 QuizGame 클래스
├── state.json       # 퀴즈 목록, 최고 점수, 플레이 히스토리가 저장되는 JSON 데이터 파일 (UTF-8)
├── .gitignore       # Git 버전 관리 제외 파일 목록 (__pycache__ 등)
└── README.md        # 프로젝트 소개 및 문서
```

## 6. 데이터 파일 설명 (`state.json`)

- **파일 경로**: 프로젝트 루트 디렉터리의 `state.json`
- **인코딩**: `UTF-8`
- **역할**: 프로그램을 종료하고 다시 실행해도 사용자가 추가/삭제한 퀴즈 목록, 최고 점수, 게임 플레이 히스토리가 그대로 유지되도록 영속성을 제공합니다. 파일이 없을 때는 기본 퀴즈 5개로 자동 생성되며, JSON 문법 오류나 필수 키 누락 등 손상 발생 시 예외(`try/except`)를 잡아 안내 후 기본 데이터로 안전하게 초기화합니다.
- **데이터 스키마 예시**:

```json
{
    "quizzes": [
        {
            "question": "마블 시네마틱 유니버스(MCU)에서 타노스가 모은 인피니티 스톤의 총 개수는?",
            "choices": [
                "4개",
                "5개",
                "6개",
                "7개"
            ],
            "answer": 3,
            "hint": "공간, 마음, 현실, 힘, 시간, 영혼 스톤이 있습니다."
        }
    ],
    "best_score": 100,
    "best_correct": 5,
    "best_total": 5,
    "has_played": true,
    "history": [
        {
            "played_at": "2026-11-07 16:30:00",
            "total_questions": 5,
            "correct_count": 5,
            "hints_used": 0,
            "score": 100
        }
    ]
}
```
